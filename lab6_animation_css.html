Лабораторна робота:Анімації CSS

Приклади завантаження, складних перетворень та анімованих елементів інтерфейсу

1. Анімація завантаження (круговий loader)

Використовується @keyframes для безкінечного обертання елемента. Імітація індикатора завантаження.

2. Loader зі стрибками точок

Три точки змінюють положення по осі Y з різною затримкою. Приклад «очікування відповіді» (typing / loading).

3. Складна анімація (transform: translate + scale + rotate)

Блок рухається по траєкторії, змінює розмір і кут повороту. Демонструє комбіноване використання transform.

4. 3D перевертання картки при наведенні

При наведенні картка обертається на 180° по осі Y. Використовуються perspective, transform-style: preserve-3d.

Кнопка плавно збільшується, з'являється пульсуюча рамка. Приклад анімації елементів UI при взаємодії користувача.
